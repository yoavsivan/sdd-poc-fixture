Used Spec Kit’s flow-forward model from docs/guides/evolving-specs.md at commit 4a7341a93d944d6efe153b71da4a1adb9c2b578c: a substantial follow-up gets a new numbered feature via `/speckit.specify`, then `/speckit.plan` → `/speckit.tasks` → `/speckit.implement`. Rotate is a new user-visible capability (new locators, new secret lifecycle) rather than a living-spec edit of F1, so `specs/002-rotate-api-keys/` is the historical record beside `specs/001-api-key-auth/`.
